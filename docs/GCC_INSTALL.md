# GCC (C 컴파일러) 까는 법

https://sourceforge.net/projects/mingw-w64/files/

일단 mingw-w64로 다운로드를 받겠습니다. 이 사이트로 이동하셔셔 `Download Latest Version`을 눌러주세요.

다운로드를 받으셨으면 원하는 경로에 가서 압축을 해제하시고, 그 안에 있는 `bin` 폴더의 경로를 **반드시 복사해주세요.**

`bin` 폴더의 경로는 대략
```
C:\mingw64\bin
```
이렇게 나옵니다. (정확히 같을 필요는 없습니다.)

그 이후 윈도우에서 제어판 앱을 실행시키고 검색 창에 시스템 환경 변수 편집을 검색해 들어가 주세요.

그 이후 환경 변수를 클릭하고 위에 사용자 변수가 보입니다. 사용자 변수에서 PATH를 클릭하시고 그 밑에 있는 편집을 클릭해주세요.

환경 변수 창에서 이전에 복사했던 `bin` 폴더의 경로를 새로 만들기 누르시고 붙여넣기 하면 됩니다.

Kern 컴파일러도 bin 경로를 복사하시고 같은 작업을 반복하시면 됩니다.

터미널에서 
```
gcc --version
```
을 했을 때 버전이 나오면 GCC 컴파일러가 정상적으로 깔린 것이고

```
kern --version
```
을 했을 때 버전이 나오면 Kern 컴파일러도 정상적으로 깔린 것입니다.
