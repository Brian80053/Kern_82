# 01 입출력

일단 이 문서를 연 독자들은 모두 `README.md`를 보고 오셨으면 좋겠습니다.

만약 아직 보지 않으셨다면 [여기](../README.md)를 먼저 보고 와주세요.

---
### 우선 Hallo, Welt!를 출력해봅시다.
---

```
PROZEDUR main()
BEGIN
    SCHREIBEN("Hallo, Welt!");
END
```

아마 C언어 혹은 그와 비슷한 언어를 해보신 분은, 이것만 보더라도 어느정도 느낌이 올 것 같습니다. 그렇지만 무슨 말인지 하나도 모르겠더라도 괜찮습니다. 이제부터 차근차근 알아갈 것이니까 말입니다.

### `SCHREIBEN()`이 도대체 무엇인가?
---

아마 기존에 프로그래밍을 해보신 분이든, 아니든 간에, 코드를 보면서 가장 먼저 시선을 끈 것은, 중간에 크게 박혀있는 `SCHREIBEN()`일 것입니다.

결론부터 말하자면, `SCHREIBEN()`은 C언어 혹은 Bash의 `printf()`에 해당하는 출력을 해주는 함수입니다. 

조금 더 자세히 설명한다면, `SCHREIBEN()`은 우리가 터미널이라고 부르는 곳에서 값을 출력을 해주는 함수입니다. 

```
PROZEDUR main()
BEGIN
    SCHREIBEN("Hallo, Welt!");
END
```

다른 건 모두 일단 몰라도 좋습니다. `SCHREIBEN()`이 출력을 해준다는 것만 안다면, 이 프로그램이 "Hello, Welt!"를 출력한다는 것 정도는 알 수 있습니다.

### 그러면 다른 출력 함수는 없나?
---

코딩을 좀 해보신 분들이 여기까지 본다면 자연스럽게 다른 의문이 떠오를 것입니다.

> 다른 출력 함수는 없나?

당연히 있습니다. 바로 `AUSGABE()`라는 함수입니다. `AUSGABE`는 `SCHREIBEN()`과 본질적으로 거의 비슷합니다. 딱 하나 다른 점이 있는데, **출력 이후에 자동으로 줄바꿈이 된다는 점입니다.** 

그러니 다른 언어와 비교하자면 Bash의 `echo()`와 Python의 `print()`와 대응되는 함수입니다.

### 입력 함수 알아보기
---

당연히 출력 함수가 있으면, 입력 함수도 있는 법입니다. 출력 함수가 터미널에서 출력을 한 것과 같이, 입력 함수 또한 터미널에서 입력을 받습니다.

입력 함수는 `LESEN()`입니다. `LESEN()`은 앞서 말한 대로 터미널에서 사용자의 키보드 입력을 받는 함수입니다.

입력에 대해서 자세히 설명하려면 변수의 개념을 알아야 하므로, 변수 파트에 가서 자세한 예시를 보여드리겠습니다. 지금은 그냥 입력에 `LESEN()`을 사용한다~ 정도만 알고 계셔도 무방합니다.

### 이스케이프 문자 알아보기
---
목차에서 이스케이프 문자라고 어려운 말을 썼지만, 겁먹으실 필요는 없습니다.

```
PROZEDUR main()
BEGIN
    SCHREIBEN("Hallo, Welt!");
END
```

위 코드를 실행해봤다면, 출력이 `"Hallo, Welt!"`이 아니라 `Hallo, Welt!` 인 것을 알 수 있을 것입니다.

그렇다면 `"`를 출력하고 싶을 때는 어떻게 할까요? 
일단 써봅시다.

```
PROZEDUR main()
BEGIN
    SCHREIBEN(""Hallo, Welt!"");
END
```
출력
```
parser error: expected )
    SCHREIBEN(""Hallo, Welt!"");
```
컴파일 과정에서 에러가 나옵니다. 어디 `"`가 시작이고 끝인 지 모르기 때문에 이런 결과가 나옵니다.

이를 방지하기 위해서 이스케이프 문자를 사용합니다. 이스케이프 문자는 백슬래시 (`\`)와 조합해서 사용합니다.

대표적인 이스케이프 문자들로는 다음이 있습니다. 사실 더 있긴 한데, 이정도만 아셔도 충분합니다.

| 이스케이프 문자 | 설명 |
|:---|:---|
| `\n`| 줄바꿈을 해줍니다. |
| `\'`| `'` 문자를 출력할 수 있게 해줍니다. |
| `\"`| `"` 문자를 출력할 수 있게 해줍니다. |
| `\\`| `\` 문자를 출력할 수 있게 해줍니다. |

그러면 아까 코드를 이렇게 바꿀 수 있을 것입니다.
```
PROZEDUR main()
BEGIN
    SCHREIBEN("\"Hallo, Welt!\"");
END
```
이제 다시 출력을 해보면..

```
"Hallo, Welt!"
```
정상적으로 출력되는 모습이 보입니다.

### ;은 왜 쓰는 거지?

코딩을 처음 접하고서 코드를 보다보면 자연스럽게 이런 의문이 떠오릅니다. 

> `;` 이건 왜 쓰는 거지?

아마 C나 Java나 기타 프로그래밍 언어들을 해보셨다면 답은 간단하게 나올 것입니다. 

세미콜론, 즉 `;`은 명령어 한 문장이 끝났다는 것을 컴퓨터에게 알려주는 역할을 합니다. 그러니까 사람의 문장으로 본다면 마침표 같은 것이죠. 그래서 세미콜론을 붙이지 않고 프로그램을 짠다면 에러가 뜰 것입니다. 

또한 `;`은 함수 내에서만 쓰고, 제어문 같은 곳에는 쓰지 않는다는 원칙이 있지만, 지금 이해하기는 어려울 수 있습니다. 한마디로 하자면 `BEGIN ... END` 사이에만 쓴다고 보시면 될 것 같습니다.

그래서 세미콜론을 빼고 코드를 써본다면
```
PROZEDUR main()
BEGIN
    SCHREIBEN("Hallo, Welt!")
END
```
출력
```
    parser error: expected ;
END
```
이렇게 컴파일 에러가 나오게 됩니다.
