### 우선 예제 코드를 먼저 봅시다
---

```
PROZEDUR main()
BEGIN
    GANZ x = 0;
    LESEN(x);
    FOR (GANZ i = 0; i < x; i++)
    BEGIN
        FOR (GANZ j = 0; j < x; j++)
        BEGIN
            IF j<x-i-1 THEN
            BEGIN
                SCHREIBEN(" ");
            END
            ELSE
            BEGIN
                SCHREIBEN("*");
            END
        END
        AUSGABE("");
    END
END
```
입력
```
5
```
출력
```
    *
   **
  ***
 ****
*****
```

별이 직각삼각형 모양으로 나옵니다. `x`를 입력받아서 그 크기 만큼 직각삼각형을 출력하는 것 같은데, `FOR`과 `IF`는 또 무엇일까요? 더해서 `BEGIN ... END`에 대해서도 자세히 알아봅시다.

### BEGIN ... END에 대해
---

BEGIN과 END는 하나의 블록을 이루는 단위입니다.

위 코드에서 본다면

```
BEGIN
    SCHREIBEN(" ");
END
```
이것이 하나의 단위라고 할 수 있습니다. 이 블록 안에서 선언한 변수는 이 안에서만 사용할 수 있고, 이 범위를 스코프라고 부릅니다. 상위 블록에서 선언한 변수는 하위 블록에서 사용할 수 있지만, 그 반대는 불가능합니다. 

```
PROZEDUR main()
BEGIN
    GANZ a = 10;
    BEGIN
        GANZ b = 20;
        AUSGABE(a);
        AUSGABE(b);
    END
    AUSGABE(a);
    AUSGABE(b);
END
```

```
semantic error: unknown variable: b
    AUSGABE(b);
            ^
```

이 경우 `a` 변수는 더 큰 블록에서 만들어졌기 때문에 정상적으로 나오지만, `b`는 안에 작은 블록에서 선언되었기 때문에 밖에서 출력을 할 수 없습니다.

### IF
---
`IF` 문은 Kern 82에서 조건을 다루는 가장 범용적인 방법입니다. `IF`는 보통 이렇게 사용합니다.

```
IF (통과 할 조건) THEN
BEGIN
...
END
```

`IF`문은 조건이 참이 되어야 블록 안으로 들어감으로, 참이 될 조건을 써넣으면 됩니다. 한마디로 그 안에 들어있는 조건은 `BOOL`값입니다.

그러므로 이전 코드의 `IF`문은
```
IF j<x-i-1 THEN
BEGIN
    SCHREIBEN(" ");
END
```
`j`와 `i` 그리고 입력받은 `x` 값이 있을 때 $j < x - i - 1$을 만족할 때 공백을 출력하는 것입니다.

또한 `IF`문의 경우 조건을 만족하지 못할 경우 밑으로 내려가게 되며, 그 밑에서 다시 `ELSE IF`와 `ELSE`를 통해 추가적인 조건문을 붙일 수 있습니다.

```
PROZEDUR main()
BEGIN
    CHAR a;
    LESEN(a);
    IF a == 'A' THEN
    BEGIN
        AUSGABE("Average");
    END
    ELSE IF a == 'B' THEN
    BEGIN
        AUSGABE("Below Average");
    END
    ELSE IF a == 'C' THEN
    BEGIN
        AUSGABE("Can't Eat Dinner");
    END    
    ELSE IF a == 'D' THEN
    BEGIN
        AUSGABE("Don't Go Home");
    END        
    ELSE
    BEGIN
        AUSGABE("Find a New Family");
    END
END
```

꽤 장문의 코드이지만 구성이 단조로워 이해하기는 어렵지 않을 것입니다. `a`를 입력받아 A가 맞으면 "Average"를 출력, 아니면 B일떄 "Below Average"를 출력, 그렇게 내려가다가 마지막에 모두 통과하지 못하면 ELSE 블록으로 들어가는 방식입니다.

### SWITCH ~ CASE
---
그러면 조건문은 이게 전부일까요? 당연히 아닙니다. `SWITCH ~ CASE`문이라는 것이 존재합니다. `SWITCH ~ CASE`문은 이런 형식을 사용합니다.

```
SWITCH (GANZ/LANG/CHAR 변수)
BEGIN
    CASE 변수 값:
    BEGIN
    ...
    END
    ...
    DEFAULT:
    BEGIN
    ...
    END
END
```

변수 하나를 잡고, 그 변수의 값이 무엇인 지에 따라 블록에 들어가는 방식입니다. 더해서 모든 변수에 만족하지 못하면 `DEFAULT` 블록에 들어갑니다. C의 `switch ~ case`문은 복수 이상의 조건을 만족할 경우 모두 들어가지만, Kern 82의 경우 그러지 않습니다. 따라서 python3의 `match ~ case`문과 유사합니다. 만약 복수 이상의 조건을 만족할 때 모두 통과하게 하고 싶으면 `FALLTHROUGH` 명령어를 끝에 넣어야 합니다.

따라서 이전의 코드를 바꿔본다면
```
PROZEDUR main()
BEGIN
    CHAR a;
    LESEN(a);
    SWITCH a
    BEGIN
        CASE 'A':
        BEGIN
            AUSGABE("Average");
        END
        CASE 'B':
        BEGIN
            AUSGABE("Below Average");
        END
        CASE 'C':
        BEGIN
            AUSGABE("Can't Eat Dinner");
        END
        CASE 'D':
        BEGIN
            AUSGABE("Don't Go Home");
        END    
        DEFAULT:
        BEGIN
            AUSGABE("Find a New Family");
        END        
    END 
END
```

이런 방식으로 바꿀 수 있습니다.

### WHILE
---
이제는 반복문에 대해서 알아봅시다. 반복문으로는 `WHILE`과 `FOR`이 존재합니다. 먼저 `WHILE`은 대략 이런 구조로 작성합니다.

```
WHILE (통과할 조건)
BEGIN
...
END
```

`WHILE`문은 통과할 조건이 참인 동안 계속 루프를 도는 구문입니다. `WHILE` 자체로는 별다른 특이 사항이 없기 때문에 바로 예시 코드 보고 넘어가겠습니다. 

```
PROZEDUR main()
BEGIN
    GANZ x = 10;
    WHILE (x > 0)
    BEGIN
        AUSGABE(x);
        AUSGABE("LAUNCH");
        x--;
    END
END
```

`x` 변수가 10에서 0까지 내려가면서 `x`와 LAUNCH를 출력하는 코드입니다.

### FOR
---
Kern 82에서 반복문을 표현하는 또다른 방법으로 `FOR`문도 존재합니다. `FOR`문의 기본 형식은 다음과 같습니다.

```
FOR (초기식;조건식;증감식) 
BEGIN
...
END
```

`FOR`문은 기본적으로 변수 하나를 선언하고 조건 하에서 변수를 증감하며 이어집니다. 조건이 꼭 변수와 관련 있을 필요는 없습니다.

```
FOR (GANZ i = 0; i < 10; i++) 
BEGIN
...
END
```
이 `FOR`문은 `i`를 0부터 10 이전까지 하나씩 늘리며 루프를 돌겠다는 뜻입니다.

`i`는 관례적으로 사용하는 값이며, `FOR`문이 한 번에 여러번 중첩된 중첩 반복문에서는 관례적으로 `j`, `k` 값을 사용합니다.

```
PROZEDUR main()
BEGIN
    GANZ x = 5;
    FOR (GANZ i = 0; i < x; i++)
    BEGIN
        FOR (GANZ j = 0; j <= i; j++)
        BEGIN
            SCHREIBEN("*");
        END
        AUSGABE("");
    END
END
```

따라서 이 코드의 출력은
```
*
**
***
****
*****
```
이런 방식으로 나옵니다.

### 무한 루프와 반복 제어문
---

지금까지 반복문에 대해서 배워보았는데, 그렇다면 반복문을 의도적으로 무한히 반복하게 하면 어떻게 될까요?

```
WHILE(WAHR)
```
이나
```
FOR(;;)
```
같은 방식으로 말입니다.

당연히 이런 구문들은 Kern 82에서 가능합니다. 다만 이를 사용하게 된다면 컴퓨터가 터져버릴 것이므로(실은 그 전에 강제 종료를 합니다.) 저희는 조건과 반복 제어문을 통해 미리 빠져나게 할 수 있습니다.

첫번째로는 `ABBRUCH`가 있습니다. `ABBRUCH`는 실행 중이던 반복문을 즉시 중단하고 빠져나가는 역할을 합니다. C에는 이와 비슷한 `break`가 있는데, `break`가 `switch ~ case` 문에도 사용되는 것과 달리 `ABBRUCH`는 오직 반복문에만 적용됩니다.

두번째로는 `WEITER`가 있습니다. `WEITER`은 C의 `continue`와 비슷한 형태의 구문으로 현재 반복을 건너뛰고 다음 반복으로 갑니다.

예시 코드는 다음과 같습니다.

```
PROZEDUR main()
BEGIN
    GANZ x;

    WHILE (WAHR)
    BEGIN
        LESEN(x);

        IF x == 0 THEN
        BEGIN
            ABBRUCH;
        END

        IF x < 0 THEN
        BEGIN
            WEITER;
        END

        AUSGABE(x);
    END
END
```
입력값으로 `x`가 0일 때 종료되고, 0보다 작으면 값이 출력되지 않고, 0보다 크면 값이 출력되는 모습을 볼 수 있습니다.
