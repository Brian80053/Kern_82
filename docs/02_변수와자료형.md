# 02 변수와 자료형

일단 이 문서를 연 독자들은 모두 `01_입출력`을 보고 오셨으면 좋겠습니다.

만약 아직 보지 않으셨다면 [여기](01_입출력.md)를 먼저 보고 와주세요.

---
### 우선 예제 코드를 먼저 봅시다
---
```
PROZEDUR main()
BEGIN
    GANZ x = 0;
    LESEN(x);
    AUSGABE(x);
    AUSGABE(CHAR(x));
    GLEIT y = 3.14;
    AUSGABE(y);
    BOOL K = WAHR;
    AUSGABE(K);
END
```

아는 명령어들이 군데 군데 보입니다. 가장 먼저 `LESEN()`과 `AUSGABE()`가 눈에 띄네요. `LESEN()`은 입력 받는 거라고 했고, `AUSGABE()`는 출력이라고 했으니, 대략 `x`라는 것을 입력 받아서 출력하고 `y` 와 `k` 라는 것도 출력하는 것 같습니다.

### 변수가 무엇인가?
---
변수는 쉽게 말해서 값을 담은 상자입니다. 값을 상자에 담고, 이후에 다시 사용할 수 있게 하는 것입니다. 

그러니 이 코드에서 변수는  `x`, `y`, `K` 가 있는 것입니다.

```
GANZ x = 0;
```

간단하게 이 줄부터 봅시다. 이 줄은 변수를 선언하는 역할을 하고 있습니다. `x`라는 변수에 `0`이라는 값을 담고 있다고 보면 됩니다. 그렇다면

```
GLEIT y = 3.14;
BOOL K = WAHR;
```

이 경우 `y`에는 3.14라는 값을, `K`에는 `WAHR`이라는 값을 담고 있습니다.

참고로 `=`은, 오른쪽의 있는 값을 왼쪽에 담는 연산자라고 지금은 생각하셔도 좋습니다.

더해서, 변수 이름으로 모든 것을 사용할 수는 없는데, 이미 언어에서 사용 중인 키워드는 사용할 수 없습니다. 대략 이런 것들이 있습니다.

| 키워드 목록 | 분류 |
|:---|:---|
|`BEGIN`, `END`, `FUNKTION`, `PROZEDUR`, `RÜCKGABE`| 구조/루틴 |
| `IF`, `THEN`, `ELSE`, `FOR`, `WHILE`, `SWITCH`, `CASE` 등| 제어 |
| `GANZ`, `LANG`, `GLEIT`, `BOOL`, `CHAR`, `KETTE`| 기본 자료형 |
| `WAHR`, `FALSCH`, `AND`, `OR`, `NOT`, `XOR`| 논리 값/연산|
등등등..

키워드들이 대부분 대문자인 관계로, 변수 명은 소문자로 짓는 것을 권장합니다.

변수는 알파벳 소문자와 대문자, 언더바(_)와 숫자로 구성되어야 하며, 첫 글자로 숫자가 올 수는 없습니다. 움라우트의 경우는 사용이 가능은 하지만, 호환성 문제로 인해서 사용하지 않는 것을 권장드립니다.

### 자료형에 대해 알아보자
---

변수는 값을 담을 수 있는 상자이지만, 모든 값을 담을 수는 없습니다.

다시 코드를 봅시다.

```
GANZ x = 0;
```
`x`는 변수명이고, `=`은 값을 대입하는 연산자, `0`은 값이라는 걸 배웠습니다. 그런데 `GANZ`는 도대체 무엇일까요? `GANZ`는 변수에 어떤 값만을 넣어라~ 하고 지정하는 '자료형'이라고 부릅니다.

### 자료형에는 어떤 것이 있을까?
---

Kern 82에서 제공하는 기본 자료형은 6개가 있습니다. 
이를 표로 정리하면 다음과 같습니다.

| 자료형 | 설명 |
|:---|:---|
|`GANZ`| 2byte 정수형  |
| `LANG` | 4byte 정수형 |
| `GLEIT`| 4byte 실수형 |
| `CHAR` | 1byte 문자형 |
| `BOOL` | 1bit 논리값 |
| `KETTE`| 고정 용량 문자열 |

각 자료형을 하나 하나 자세히 살펴보도록 하겠습니다.

### 1. Ganz/Lang
---
`Ganz` 타입과 `Lang` 타입은 모두 변수가 정수를 담을 수 있게하는 타입입니다.

그러나 컴퓨터는 큰 정수를 모두 저장할 수 없고, 어느 정도 길이까지의 정수만 저장할 수 있습니다. 이 저장할 수 있는 범위에서 차이가 생깁니다.

| 자료형 | 범위 |
|:---|:---|
|`GANZ`| $-2^{15} \leq X \leq 2^{15}-1$ |
| `LANG` | $-2^{31} \leq X \leq 2^{31}-1$ |

즉 `GANZ`의 범위는 $-32,768 \sim 32767$, `LANG`의 범위는 $-2,147,483,648 \sim 2,147,483,647$ 입니다. 대략 21억 가량이 Kern 82에서 기본 정수형으로 표현할 수 있는 한계치입니다.

이 값을 넘는 경우를 오버플로우라고 하는데, 오버플로우의 경우 값이 의도하던 값과 다르게 나올 수 있기 때문에 주의해야 합니다.

오버플로우 테스트를 한 번 해봅시다.
```
PROZEDUR main()
BEGIN
    GANZ a = 32767;
    AUSGABE(a);
    a=a+1;
    AUSGABE(a);
END
```

출력
```
32767
Kern82 runtime error at 5:8: integer overflow or cast out of range
```

런타임 에러가 나오는 모습입니다. C언어는 오버플로우를 정의되지 않은 동작으로 규정하지만, 실행 자체는 가능함과 반대로, 런타임 에러로 이를 사전에 막는 모습을 보여줍니다.

### 2. GLEIT
---

GLEIT는 정수뿐만 아니라 실수까지도 저장할 수 있는 자료형입니다. 부동소수점 방식을 사용해 저장을 하는데, 자세한 것은 알지 못해도 괜찮고, 모든 자리수를 정확히 저장하지 못한다는 것만 기억하시면 됩니다.

GLEIT의 범위는 부동소수점 방식을 사용해 매우 큰 편입니다.

| 자료형 | 범위 |
|:---|:---|
|`GLEIT`| $-3.4 × 10^{38} \sim 3.4 × 10^{38}$ |

범위는 매우 큰 편이지만, 저장이 모두 정확한 것은 아닙니다. GLEIT가 안전하게 저장할 수 있는 범위는 고작 소수점 아래 6 ~ 7 자리 정도 이고, 그 뒤에서는 정확성이 보장되지 않습니다.

```
PROZEDUR main()
BEGIN
    GLEIT y = 3.14;
    AUSGABE(y);
END
```
이 코드의 실행 결과는 3.14가 아닙니다.

```
3.1400001
```

3,1400001이 나오는 모습입니다. 유효자리수 그대로, 6자리까지는 정확하지만 7번째 자리에서 틀리는 모습을 볼 수 있습니다.

### 3. CHAR/KETTE
---

`CHAR`은 문자를 저장할 수 있게 하는 1바이트 자료형입니다. C언어의 `char`과 다르게, Kern 82의 `CHAR`은 본질적으로 부호가 없습니다. 즉 범위는 다음과 같습니다.

| 자료형 | 범위 |
|:---|:---|
|`CHAR`| $ 0 \sim 255 $ |

더해서, Kern82의 문자 시스템은 유니코드를 지원하지 않습니다. (즉 한글을 입력할 수 없습니다.) 대신, 아스키 코드를 변형한 독자 문자 체계를 사용합니다.

0부터 127까지는 아스키 코드 형식으로 되어있고, 그 뒤에는 유럽 언어들에서 쓰이는 다이어크리틱 일부와, 수학 기호들이 존재합니다.

전체 코드는 [여기](부록01_독자코드전문.md)에서 확인하실 수 있습니다.

`CHAR`은 연산이 불가능하지만 내부적으로는 숫자로 저장되고, 이들끼리 비교할 수 있습니다.

```
PROZEDUR main()
BEGIN
    CHAR x = 'A';
    AUSGABE(GANZ(x));
    CHAR y = 'B';
    AUSGABE(x<y);
END
```

출력
```
65
WAHR
```

'A'는 65로 저장되기 때문에 `GANZ`형으로 출력했을 때 65가 나오며, 'B'는 66이므로 `x`가 `y`보다 더 작습니다. 따라서 결과로 `WAHR`,즉 참으로 나옵니다. `WAHR`에 대해서는 다음 `BOOL` 자료형에 대해 배울 때 더 자세히 설명하겠습니다.

`KETTE`는 문자열을 나타내는 전용 자료형입니다. 자세한 사항은 리스트와 문자열을 배울 때 배우도록 하겠습니다.

### 4. BOOL
---

`BOOL`은 1비트의 진리값으로 오직 거짓과 참, `FALSCH`와 `WAHR`값이 존재합니다.

긴 말하지 않고 예시 코드를 본다면

```
PROZEDUR main()
BEGIN
    GANZ x = 3;
    GANZ y = 2;
    BOOL n = x<y;
    AUSGABE(n);
    BOOL m = x>y;
    AUSGABE(m); 
END
```

출력
```
FALSCH
WAHR
```

`x`가 `y`보다 작다는 것은 거짓이므로 `n`은 `FALSCH`가 저장되고, 반대는 참이므로 `m`은 `WAHR`이 저장됩니다.

### 다른 언어와 비교

마지막으로 C언어와 비교를 해보자면, `GANZ`는 `short`, `LANG`은 `int`, `GLEIT`는 `float`, `CHAR`은 `unsigned char`, `BOOL`은 `bool`에 대응할 수 있습니다.
