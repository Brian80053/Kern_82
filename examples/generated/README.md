# 생성 C 참고 출력

기존에 저장소에서 관리하던 예제 C 파일을 내용 변경 없이 모았다. 각 파일은 생성 당시 compiler의 출력이며 현재 소스와 항상 일치하지는 않는다. `maximum.c`와 `startriangle.c`처럼 대응 예제 이름이 다르거나 소스가 다른 폴더에 있는 출력도 보존했다.

새로 컴파일할 때는 루트 README의 명령처럼 `build/examples/`에 출력한다. `.gitignore`는 일반 생성 C를 제외하고 이 폴더의 참고 C 파일은 보관하도록 설정돼 있다. 기존 실행 파일은 `bin/examples/`에 있다.
